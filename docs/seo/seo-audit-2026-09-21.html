The “unlock”: there is nothing locked

I checked every layer where a crawler could be stopped. All are open today, so there is no switch to flip on the site itself.

Two things I could not see from here. (1) Vercel’s managed Bot Protection ruleset is not shown by the CLI — check Vercel → project → Firewall → Bot Management; it should be off or on “Log”, never “Challenge”, for verified bots. (2) Whether the site is verified in Google Search Console / Bing Webmaster Tools — there is no verification tag in the code, so it is either done by DNS or not done. That registration is the real “unlock”.

Recommended next, in priority order

  1. Register the site with Google Search Console and Bing Webmaster Tools, then submit https://www.tarekalaaddin.com/sitemap.xml. Use a Domain property verified by DNS TXT so apex and www are both covered. This is the step that actually starts indexing and the only way to see coverage errors.
  2. Make the apex redirect permanent. Vercel → project → Settings → Domains → tarekalaaddin.com → redirect to www with status 308. A 307 tells Google the move is temporary, so link equity to the bare domain is not consolidated.
  3. Add a “Related posts” block to post pages (3–4 posts from the same category/tags). Today every post is a dead end reachable only from /blog and the sitemap. This is the single biggest on-site ranking lever left, and it also helps readers. It is a UI change, so I have not built it without your say.
  4. Shorten what Google displays. Drop the “ | Tarek Alaaddin” suffix on posts (one line, via title.absolute) which cuts titles over ~70 characters from 81 to 18, and trim the 21 long descriptions to ≤155 chars over time. Also add a rule to the blog-post pipeline: title ≤60, description ≤155, at least two internal links per post.
  5. Homepage LCP. The hero cut-out is a 642 KB PNG source. It is already priority-loaded through next/image; re-exporting the source as a ~1200 px-wide WebP/AVIF should pull LCP toward the 2.5 s target.
  6. Homepage relevance. The title “Software Engineer & Product Builder” names no searchable topic. If the goal is to rank for AI automation / agentic coding work, say so in the homepage title, description and H1.

Method and limits

Live pages fetched with curl (default and Googlebot user agents); frontmatter of all 95 MDX posts parsed by script; JSON-LD parsed from a live post; Lighthouse mobile run locally in headless Chrome (Google’s PageSpeed API was over its shared daily quota, so there is no real-user field data in this report); Vercel Firewall read with vercel firewall overview and rules list. No Vercel settings were changed.
