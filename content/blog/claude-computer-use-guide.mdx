## What Claude Computer Use Actually Is

At its core, Claude Computer Use gives Claude eyes and hands for your computer. Claude takes a screenshot of your screen, analyzes what's visible, decides what to do next, then executes actions — clicks, keystrokes, scrolling — and repeats the loop until the task is done.

Think of it as a remote assistant who can see your screen and control your mouse. Except this assistant works at machine speed, doesn't forget instructions, and costs a fraction of a human VA.

The technology launched as a developer-only API beta back in October 2024. What's new as of March 23, 2026 is that it's now available to regular users through Claude Cowork and Claude Code on macOS — no coding required.

<Callout type="info">
Claude doesn't just jump straight to clicking your screen. It follows a smart priority hierarchy: built-in connectors first (Gmail, Slack, Google Calendar), then browser navigation, then full screen control as a last resort. This means it takes the fastest path available for any given task.
</Callout>

## How It Works Under the Hood

The system operates through an agent loop — five steps, repeated until the task is done:

1. **You describe a task** — "Book a flight to Austin for next Thursday" or "Fill out this expense report"
2. **Claude captures a screenshot** of your current display
3. **Claude analyzes the screen** and decides what action to take (click a button, type text, scroll down)
4. **Your system executes the action** and takes another screenshot
5. **Claude evaluates the result** and either continues with the next action or reports completion

Each cycle takes a few seconds. For simple tasks, you'll see 5-10 cycles. For complex multi-step workflows, expect 20-50 cycles. The model supports a comprehensive set of actions including clicks (left, right, double, triple), keyboard input, scrolling, drag-and-drop, and even zooming into specific screen regions for precision.

On the benchmarks, Claude leads by a wide margin. It scores 61.4% on OSWorld — the standard benchmark for autonomous computer control — where competing systems scored roughly 7-8% at the time of Anthropic's API launch, making Claude approximately 8x ahead. On WebArena for web navigation, it holds the top spot.

## Three Ways to Access Computer Use

### 1. Cowork (Easiest — No Code Required)

This is what most people should start with.

**Requirements:**
- A Mac (Windows support is confirmed but not yet available)
- Claude Desktop app (latest version from claude.com/download)
- Claude Pro ($20/month) or Claude Max ($100-$200/month) subscription

**Setup in four steps:**
1. Download or update Claude Desktop
2. Go to **Settings → General** in the Desktop app section
3. Toggle on **"Computer use"**
4. Open Cowork and start asking Claude to do things on your computer

That's it. Claude will ask permission per application before accessing anything — so you stay in control of what it can touch.

### 2. Dispatch (Remote Control from Your Phone)

Dispatch launched on March 17, 2026, and it pairs perfectly with computer use. The idea: you assign tasks from your phone, and Claude executes them on your Mac while you're away.

**Setup takes about two minutes:**
1. Open Claude Desktop on your Mac and go to Cowork
2. Click "Dispatch" in the left panel
3. Scan the QR code with your phone
4. Start sending tasks from anywhere

The catch: your Mac must stay awake and Claude Desktop must remain open. If your computer sleeps, Dispatch stops. There's also no completion notification yet — you have to check back to see if the work is done.

### 3. API (Full Developer Control)

For developers who want maximum flexibility, the API lets you integrate computer use into any application. You'll need Docker or a VM for the sandboxed environment.

```python
import anthropic

client = anthropic.Anthropic()

response = client.beta.messages.create(
    model="claude-opus-4-6",
    max_tokens=1024,
    tools=[{
        "type": "computer_20251124",
        "name": "computer",
        "display_width_px": 1024,
        "display_height_px": 768,
        "display_number": 1,
    }],
    messages=[{
        "role": "user",
        "content": "Open the spreadsheet on the desktop and summarize Q1 revenue"
    }],
    betas=["computer-use-2025-11-24"],
)
```

The API supports Claude's latest models — Opus 4.6 and Sonnet 4.6 use the newest `computer_20251124` tool version, while older models like Opus 4.5 use `computer_20250124`. Anthropic provides a full reference implementation with Docker on their GitHub.

## The Honest Pros

**It works with anything.** No API integration needed. If an application has a visual interface, Claude can interact with it. Legacy enterprise software, obscure SaaS tools, desktop applications with no automation hooks — Claude doesn't care. It clicks buttons like a human.

**The tool hierarchy is smart.** Claude doesn't waste time screenshotting your screen when a faster connector exists. Gmail, Slack, and Google Calendar all have direct connectors. The browser gets used for web tasks. Screen control is the fallback, not the default. This means most tasks complete faster than you'd expect.

**Dispatch changes the game.** Assigning work from your phone while Claude executes on your Mac is genuinely useful. "Compile this report from the spreadsheets in my Downloads folder" — send from your commute, arrive to completed work.

**Visual comprehension is impressive.** Claude understands UI layouts, can read text on screen, identifies buttons and input fields, and navigates complex interfaces with reasonable accuracy. The 61.4% OSWorld score isn't perfect, but it's dramatically ahead of alternatives.

**No setup barrier for Cowork users.** One toggle in settings. No Docker, no Python, no configuration files. This accessibility matters because it means non-technical users can benefit immediately.

<Callout type="warning">
Computer use is still classified as a research preview. Anthropic explicitly states: "Computer use is still early compared to Claude's ability to code or interact with text." Expect occasional mistakes, especially with complex multi-step workflows.
</Callout>

## The Honest Cons

**It's Mac-only right now.** If you're on Windows or Linux, you're limited to the API approach with Docker. Anthropic confirmed Windows support is coming, but no timeline. This is a significant limitation given Windows' market share.

**Speed is the tradeoff.** Each screenshot-analyze-act cycle takes several seconds. A 20-step task might take 2-3 minutes where a human could do it in 30 seconds. Computer use excels at tasks you'd rather not do at all — not tasks where speed matters.

**It makes mistakes.** Claude can misidentify UI elements, click the wrong button, or get stuck in loops. Complex multi-step workflows occasionally go sideways. You'll want to supervise important tasks, especially early on.

**Security requires attention.** Claude sees everything on your screen — including passwords, financial data, and personal information. Certain app categories (investment platforms, cryptocurrency exchanges) are blocked by default. Anthropic recommends against using it with banking, healthcare, or legal documents. This is sensible advice.

**Token costs escalate on the API.** Each screenshot consumes vision tokens, and complex tasks can require dozens of screenshots. API users have reported unexpectedly high costs for intensive automation workflows. The computer use tool definition alone adds 735 input tokens per request.

**Usage limits can be tight.** Since the March 23 launch, some Max plan users have reported on GitHub that session limits exhaust faster than expected during active computer use — anecdotally as little as 1-2 hours instead of typical session windows. This appears to be a temporary growing-pain issue that Anthropic is likely to address.

**Your computer has to stay on.** For Dispatch, your Mac can't sleep and the app can't close. This is a constraint that matters if you're sending tasks from your phone expecting them to complete while you're away for hours.

## What to Watch Out For

Before you go all-in, keep these guardrails in mind:

**Start with supervised tasks.** Don't hand Claude your tax returns on day one. Begin with low-stakes tasks where mistakes are easily caught and corrected. Build confidence in the system before trusting it with anything critical.

**Keep sensitive data off-screen.** Close password managers, banking tabs, and anything containing private data before running computer use tasks. Claude sees everything visible on your display.

**Monitor token usage if using the API.** Set budget alerts. Complex automation workflows can consume thousands of tokens from screenshots alone. The consumer Cowork version handles this within your subscription limits.

**Have a backup plan.** Computer use will occasionally fail on complex tasks. Design your workflows so you can pick up where Claude left off rather than starting over.
